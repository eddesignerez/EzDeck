# EzDeck

EzDeck is a local Windows shortcut panel controlled from Android, a tablet, or a browser. It is an independent Windows and Android adaptation inspired by Dokke.

For development setup and Android pairing instructions, see the Portuguese [README](README.md). EzDeck is based on [Dokke](https://github.com/felipenalves/Dokke) by Felipe Alves and preserves the original MIT license and attribution in [LICENSE](LICENSE). For macOS, download the original [Dokke project](https://github.com/felipenalves/Dokke); EzDeck supports Windows plus Android/PWA clients only.
