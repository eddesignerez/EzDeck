# EzDeck

لوحة اختصارات محلية للتحكم في كمبيوتر Windows من Android أو جهاز لوحي أو متصفح. EzDeck هو تكييف مستقل لـ Windows وAndroid مستوحى من [Dokke](https://github.com/felipenalves/Dokke)، مع الحفاظ على ترخيص MIT والاعتمادات الأصلية.

![شعار EzDeck](public/ezdeck-logo.png)

## ما يتضمنه المشروع

- مضيف Windows أصلي مع أيقونة شريط النظام وPIN ومنفذ قابل للتخصيص وبدء التشغيل مع Windows واختصار سطح المكتب.
- APK لـ Android وPWA للمتصفح مع اكتشاف الشبكة المحلية والاقتران عبر PIN وتحديثات WebSocket.
- أزرار للتطبيقات والمواقع واختصارات لوحة المفاتيح، وأيقونات مخصصة وصفحات متعددة وسحب وإفلات ووضعين فاتح وداكن.
- إحدى عشرة لغة للواجهة. اللغة التي تختارها في مضيف Windows تنعكس على Android والمتصفح.

## التثبيت

نزّل `EzDeck-Setup.exe` من الإصدار الرسمي وشغّله، ثم افتح اختصار سطح المكتب. يتصل المرافق Android/PWA عبر PIN وWebSocket واكتشاف الشبكة المحلية.

راجع [دليل الاستخدام](MANUAL_DE_USO.md) و[الخريطة الذهنية](MAPA_MENTAL.md). لا تعرّض المنفذ المحلي للإنترنت.

## التوثيق والتطوير

يشرح [دليل الاستخدام](MANUAL_DE_USO.md) التثبيت والاقتران وحل المشكلات، بينما تلخص [الخريطة الذهنية](MAPA_MENTAL.md) المضيف والعملاء والشبكة المحلية. يتطلب التطوير Windows 10/11 وNode.js 20 أو أحدث: `git clone https://github.com/eddesignerez/EzDeck.git` ثم `npm ci` ثم `.\windows\run-dev.ps1`.

## الاستخدام الكامل

1. نزّل `EzDeck-Setup.exe` من [الإصدارات الرسمية](https://github.com/eddesignerez/EzDeck/releases)، ثبّته ثم افتح **EzDeck** من سطح المكتب. بيئة التشغيل مضمّنة، لذلك لا يحتاج المستخدم إلى Node.js.
2. إذا طلب Windows Firewall الإذن، اسمح للتطبيق على **الشبكات الخاصة** فقط. إغلاق النافذة يرسل المضيف إلى منطقة الإشعارات، بينما **إيقاف EzDeck** يوقفه بالكامل.
3. صِل الكمبيوتر والهاتف/الجهاز اللوحي بالشبكة Wi‑Fi نفسها. استخدم العنوان بعد **الوصول** ورمز PIN المكوّن من أربعة أرقام في Windows. يحاول APK اكتشاف المضيف تلقائيًا؛ عند الفشل أدخل IP والمنفذ يدويًا.
4. يمكن فتح العنوان نفسه في Chrome أو Safari أو Edge وإضافته إلى الشاشة الرئيسية، وهي الطريقة الموصى بها لـ iPhone/iPad.

## إنشاء اللوحة ومزامنتها

- اسحب التطبيقات إلى الأماكن الفارغة، واسحب البطاقات لإعادة الترتيب، واستخدم **X** لإزالتها.
- استخدم `+ صفحة` لإضافة صفحة و`− صفحة` لإزالة آخر صفحة فارغة.
- ينشئ زر لوحة المفاتيح أوامر مثل `Ctrl+C`، ويضيف `+` ملفات `.exe` أو `.lnk` أو `.bat` أو `.cmd`.
- انقر البطاقة لاختيار رمز مخصص واضغط **حفظ** لإرسال التغييرات إلى Android/PWA.

ترسل أوامر لوحة المفاتيح إلى نافذة Windows النشطة. قد تمنع التطبيقات التي تعمل كمسؤول هذه الأتمتة.

## الإعدادات والأمان والتوافق

- يضبط **PIN** الرمز، وينشئ **AUTO** رمزًا جديدًا، ويتغير **المنفذ** بعد إعادة تشغيل EzDeck.
- فعّل **البدء مع Windows**، واستخدم الشمس/القمر للمظهر، واختر اللغة في مضيف Windows فقط؛ يعكس Android/PWA الاختيار.
- لا تشارك PIN ولا تعرض المنفذ للإنترنت. عند فشل الاكتشاف استخدم IP والمنفذ المعروضين في المضيف.
- متوافق مع Windows 10/11 وAndroid 5.0 أو أحدث والمتصفحات الحديثة على الشبكة نفسها.

للتطوير يلزم Windows 10/11 وNode.js 20+: `git clone https://github.com/eddesignerez/EzDeck.git` ثم `npm ci` ثم `.\windows\run-dev.ps1`.
